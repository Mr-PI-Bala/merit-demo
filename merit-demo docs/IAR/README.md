# MERIT Demo IAR Usage

Keep this consumer IAR surface small and role-based:

| File | Use |
|---|---|
| `MERIT_DEMO_ECOSYSTEM_PLAN.md` | Controlling consumer SSOT, requirements, zones, and NextRel FRs |
| `MERIT_DEMO_TDD_CHECKLIST.md` | Executable Zone A/B/C/D test authority |
| `SOTU.md` | Short current-state snapshot; link to evidence, do not restate policy |
| `evidence/` | Receipts, screenshots, cloud captures, and test transcripts |

Host lifecycle policy belongs to the skills-plane IAR [MERIT_CLOSEOUT_ENFORCEMENT.iar.md](../../../merit-agent-skills/docs/IAR/MERIT_CLOSEOUT_ENFORCEMENT.iar.md) and its checklist. Do not copy that host matrix into this repo. New consumer requirements go into the ecosystem plan; new tests go into the existing TDD checklist.

Create a new IAR file only with a rationale in this README and a link from the controlling plan. Historical evidence may remain under `evidence/` without becoming a second authority.
