## Alpha blocker

`npm run test:alpha-registration` and the browser provider gate fail closed. The expected URL is:

```text
https://merit-prod.vercel.app/store/merit-demo/register
```

The deployed provider responds with a redirect to:

```text
https://merit-prod.vercel.app/portal/developers/sku-commerce/
```

That destination is the commerce guide, not the app registration form. This is a provider activation blocker for `BUG-ALPHA-001`, `FR-ALPHA-002-D`, and the free subscriber paths. No subscriber or payment data was submitted.

## Evidence boundary

The public consumer remains independent of `merit-private-vault`. The fork contract expects a new app to set its own `consumer_id`, provider registration URL, branding, and hosted identity through the public Hub/skills flow. The reference slug `merit-demo` remains a showcase slug and is not treated as an alpha commerce tenant.
